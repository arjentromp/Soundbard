# Soundbard

Soundbard is a desktop soundboard application designed for tabletop roleplaying games such as Dungeons & Dragons. It allows users to organize, manage, and play audio tracks with customizable controls and hotkeys.

## Features (Planned)

- Track-based audio organization
- Multiple playback modes (continuous, interval, trigger)
- Track-specific audio libraries
- Hotkey support
- Directory-style audio management
- Session-friendly UI layout

## Technology

- C#
- WPF (.NET)
- NAudio (planned)

## Status

Early development.

## Goals

Soundbard aims to provide a lightweight, flexible audio control tool tailored specifically for tabletop gameplay sessions.
